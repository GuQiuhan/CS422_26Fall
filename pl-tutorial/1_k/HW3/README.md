# CS422 HW3

Each exercise is in its own directory. Each directory has the K definition, a `Makefile`, and a `tests/` directory. Run `make` in a directory to kompile the definition and run all its tests. Run `make clean` to remove the build output.

The tests for Exercise 1 are my own three programs. The tests for the other exercises come from the matching exercise directories in `pl-tutorial/1_k`.
